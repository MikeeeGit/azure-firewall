# Security

Do not post credentials, state, saved plans or sensitive network information in public issues. Report vulnerabilities through the repository's private security reporting facility when available; otherwise contact the maintainer privately before disclosing exploit details.

Public validation is credential-free. Keep backend storage, OIDC identities, plan artifacts and approvals in a trusted private consumer. Firewall policy is an authorization boundary: review both inherited and child rules, DNS, routes and NSGs. A mock test or a configured firewall does not demonstrate effective isolation.
